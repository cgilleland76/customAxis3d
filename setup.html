Create the project

  1. Go to supabase.com/dashboard → New project.
  2. Name it anything. Pick the region closest to you. Set a database password and save it somewhere — you won't need it for this site, but you'll want it later.
  3. Wait for it to finish provisioning (a minute or two).

The free tier is plenty here. A project pauses after a week with zero traffic and wakes on the next visit — if that ever bites you, opening the site is enough to wake it.

Connect this site

  1. Project Settings → API (or API Keys).

6

Create your login

  1. Authentication → Users → Add user → Create new user.
  2. Use your own email and a strong password. Tick Auto Confirm User if it's offered.
  3. That's the login for Shop tools. Customers can submit requests without an account; only this login can read them back.

Upload is safe to repeat — rows are matched on their id, so nothing duplicates. Download replaces this browser's copy with the cloud's.
